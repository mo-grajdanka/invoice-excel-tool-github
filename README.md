# Счёт → Закупочная ведомость

Приложение для пополнения Excel-ведомости на основании PDF-счёта. Не требует отдельного сервера, базы данных или установки сложных сервисов: Streamlit-приложение публикуется из вашего GitHub-репозитория.

**Возможности:**

- загрузить XLSX и PDF через два отдельных поля;
- распознать таблицу товаров и услуг в PDF через OpenRouter;
- для сканов выбрать OCR `mistral-ocr`, для текстовых PDF — `cloudflare-ai`;
- вручную проверить/поправить позиции и реквизиты перед выгрузкой;
- выбрать один из **6 настроенных листов**;
- обнаружить потенциальные повторные записи;
- добавить строки *после* существующих, сохранив формулы, кеши расчётов, печатные настройки и значения старых строк;
- скачать обновлённую **копию** XLSX.

## 1. Публикация на GitHub и Streamlit

GitHub хранит исходный код. **GitHub Pages не запускает Python/Streamlit**, поэтому сам сайт публикуется на [Streamlit Community Cloud](https://share.streamlit.io/), подключённом к GitHub.

1. Создайте в своём GitHub новый репозиторий, например `invoice-excel-tool`.
2. Загрузите в него файлы этого проекта: `app.py`, `excel_writer.py`, `xlsx_patch.py`, `ocr.py`, `requirements.txt`, `.gitignore`, `.streamlit/secrets.toml.example`, `README.md` и папку `tests`.
3. Откройте <https://share.streamlit.io/> → **Create app** → **Yup, I have an app**.
4. Выберите репозиторий, ветку `main` и главный файл `app.py`.
5. В **Advanced settings → Secrets** вставьте:

   ```toml
   OPENROUTER_API_KEY = "ВАШ_КЛЮЧ_OPENROUTER"
   OPENROUTER_MODEL = "google/gemini-3.5-flash-lite"
   APP_PASSWORD = "ВАШ_СЛОЖНЫЙ_ПАРОЛЬ_ДОСТУПА"
   ```

6. Нажмите **Deploy**. Ссылка на сайт появится в вашем кабинете Streamlit.

**Важно:** если сайт будет доступен по ссылке другим людям, обязательно задайте `APP_PASSWORD`, иначе посторонние смогут отправлять счета за счёт вашего OpenRouter-ключа. Для действительно конфиденциальных документов нужны дополнительная защита доступа и доверенный хостинг. Никогда не загружайте `secrets.toml`, PDF-счета или исходную ведомость в публичный GitHub-репозиторий. Ключ должен быть только в настройках Streamlit Secrets (или в переменных среды при локальном запуске).

## 2. Локальный запуск

Python 3.11–3.13:

```bash
python -m venv .venv
# Windows: .venv\Scripts\activate
# macOS/Linux: source .venv/bin/activate
pip install -r requirements.txt
```

Создайте `.streamlit/secrets.toml` по примеру `.streamlit/secrets.toml.example`, задайте свой API-ключ и запустите:

```bash
streamlit run app.py
```

Можно запускать без ключа: тогда работает **ручное добавление позиций**, но не AI-распознавание.

## 3. Как пользоваться

1. Загрузите **актуальную версию** ведомости `.xlsx`.
2. Загрузите счёт `.pdf`.
3. Выберите лист, в который нужно добавить позиции.
4. Нажмите **Распознать PDF**.
5. Сверьте поставщика, номер и дату счёта, количества, цену и стоимость по оригиналу. При необходимости исправьте данные, снимите галочки с лишних позиций.
6. Нажмите **Скачать обновлённый Excel**.
7. Для следующего счёта загружайте **уже обновлённую копию**, иначе ранее добавленные данные не войдут в новый файл.
